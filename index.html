音系要点（据文献）
  1. 清浊对立，而非送气对立：通城方言只有清浊对立，没有送气与不送气的对立；古全浊声母与次清（送气）声母合流为浊音声母（“次清化浊”），故 b d dz dʑ g 等浊音声母是通城话的关键特征，也是幕阜山“浊音走廊”的典型表现。
  2. 没有卷舌音：无 zh ch sh r 一类卷舌声母，舌尖音一律作 ts dz s z；另有普通话所无的舌根鼻音 ŋ（鹅、安、鄂）与舌面鼻音 ȵ（泥、银、捏）。
  3. 六个声调（城关／隽水）：古平声、去声按清浊各分阴阳，古上声浊声母字归阳去，入声保留且自成一调。西片石南等地入声再分「全入／次入」而成七调（石南：全入 55、次入 35）。
  4. 入声韵尾：多数点收喉塞尾 [-ʔ]，通城另有 [-l] 一类韵尾，部分点入声韵尾出现鼻化／鼻音化（[-n]、[-ŋ]），是边界方言的创新演变。
  5. 内部差异：县内大体分三片——隽水等「通城声」（城区）、北港大坪等「湖南声」（西片，近平江、临湘）、麦市塘湖等「崇阳声」（东片）。三者声韵调系统可对比，本表以城区「通城声」为基准。
使用说明
  1. 「声母 ▾ / 韵母 ▾ / 读音 ▾ / 声调 ▾」四个单元格均为可输入 + 可下拉：点右侧箭头从音系列表中选择，或直接键盘输入（含自定义音标、变读、白读等）。
  2. 「读音」点 ⤵ 会按「声母＋韵母＋调值」合成，例：b + a + 312 → ba³¹²；声调只选调类而未写调值时，自动取该调类在城关话的调值。
  3. 下拉列表中的例字来自上列文献的调查字，可用于核对读音是否与当地实际一致；不一致时请直接输入实际读音并在「备注」中记录发音人、村镇等信息。
  4. 记录建议：每个字尽量注明发音人年龄、性别、村镇（通城内部差异大，同字不同村可能不同音），有文白异读时分别记录。
  5. 数据实时保存在本机浏览器（localStorage）；导出 JSON 可备份与跨设备续录，导出 Excel 可用 Excel／WPS 继续整理统计。

设计 · 制作
通城方言属赣语大通片，兼具湘语特征，保留古入声，被语言学界视为汉语史的「活化石」。本表为记录工具：普通话音系由程序生成，通城音系为文献参考值，最终以当地实际读音为准。
