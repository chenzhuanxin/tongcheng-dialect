# 通城方言资料库 (Tongcheng Dialect Resources)

湖北省咸宁市**通城县**方言（通城话，属**赣语大通片**，赣语与湘语交汇、含客籍话/麦市方言岛）的相关**文献、真人语音样本、数据表格与检索来源**汇总。本仓库为个人研究整理，含论文 PDF、网络文章、B 站真人录音切片与合成实验音频。

> ⚠️ 版权与出处：`01_文献论文` 中的论文 PDF 版权归原作者与期刊；`03_语音样本` 的真人音频来自「中国语言资源保护工程采录展示平台」通城点（发音人 Mond）经 B 站录屏获取，版权归语保工程/UP 主；本仓库仅作学习研究用途，请勿商用。若涉侵权请联系删除。

## 语音样本说明

- **真人音档**（BV1Hg411e7ya《通城话音档·赣语大通片》，UP 杨智程，发音人 Mond，2022）：5 分 P（语音/常用词汇/语法例句/长篇语料×2）。用能量 VAD 按朗读停顿切成 824 段单字/词/句切片，画面文字经 720p + 框坐标聚类 OCR 重建对应表。
- **真人录屏**（BV18qceezED2《赣语大通片-通城》）：UP 手机录屏播放语保平台通城点，音轨即真人通城话；按画面每屏切 102 段，配「普通话/通城话/音标/时间」表。
- **合成实验**：早期无真人音频时，用 1000 字表音标做的共振峰合成（含 F0 连续建模、连读、jitter、混响），仅作方法演示，非真人。

## 数据表格说明

- **1000 字读音表**：来自语保 `POST /api/mongo/resource/normal (id=07D36)`，老年男性与青年男性各 1000 字，含方言记音、声母/韵母/五度调值；其中 227 字两代读音不同。
- **720p 词表**：对 B 站音档画面重新抽帧、OCR、按框坐标分列，得「序号/普通话/通城话/音标/时间」。
- **词汇切片对齐表**：读一条切一条的顺序对齐结果。

## 已知限制

- OCR 的中文词较准，**IPA 音标/声调符号仍有识别噪声**（变音符、塞擦音 ɕ/tɕ 等）。
- 切片↔词条为**顺序/比例对齐**，个别可能错位；录屏每屏为整段对话，非严格一句一切。
- 语保平台音频接口对普通账号返回 401，本库真人音频经 B 站录屏获取。

## 方法与工具

Python + requests/playwright（抓取）· ffmpeg（抽音/抽帧）· rapidocr-onnxruntime（中文 OCR）· numpy/scipy（VAD、共振峰合成）· openpyxl/python-docx（表格与文档）。

## 在线工具

**通城方言字音记录表**（本仓库 `index.html`，[在线打开](https://chenzhuanxin.github.io/tongcheng-dialect/)）：5000 常用汉字 × 普通话音系（拼音/声母/韵母/声调）× 通城方言音系录入表。通城方言声母、韵母、读音、声调（六声：阴平312/阳平22/上声31/阴去24/阳去33/入声5）均支持输入与下拉选择，附文献音系参考表；数据可导出 Excel / JSON，可导入 JSON 续录。

单文件离线可用（下载 `index.html` 双击即开，数据存本机浏览器）。
